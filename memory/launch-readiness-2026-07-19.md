## 最终验证结果

- `npm run verify`：通过；类型检查 0 error / 0 warning，6 项推荐与内容测试全部通过。
- 内容审计：300 条唯一 Idea，15 个分类配额全部通过。
- 生产构建：324 个静态页面生成成功，其中 322 个为可索引页面。
- SEO 审计：站点地图完全一致、无孤儿页、首页包含 300 个 Idea 链接。
- 浏览器 QA：桌面和移动端关键流程、可访问性焦点、图片、分享与错误监控全部通过。
- 模拟慢速移动网络：首页 LCP 约 1.65 秒、传输约 248 KB；这是实验室数据，不代替上线后的真实用户数据。

## 上线前视觉门禁

1. 按 `assets/idea-image-generation-plan.json` 生成 300 张 3:2 写实图片。
2. 每张图必须同时通过“活动一眼可识别”和“明确两人共同约会”两项人工看图检查。
3. 审核后的文件放入 `assets/generated-idea-images/`，通过带 `--reviewed` 参数的导入命令安装；未经审核的文件不能激活。
4. 生成图替换完毕后重新执行全站 contact sheet、移动端裁切和 Picker 结果组合检查。

## 上线后验证

以下事项不阻塞当前构建发布，但必须在公开环境完成：

1. 将 `dist/` 部署到 `date-night-ideas.com`，确认 HTTPS、301 规则与生产 canonical。
2. 在 Google Search Console 提交 sitemap，并观察抓取、索引覆盖率和 canonical 选择。
3. 用真实用户数据检查 Core Web Vitals；实验室结果不能证明生产环境一定通过。
4. 持续建设自然外链、品牌提及和内容更新节奏。站内优化已完成，但不能在发布前声称关键词已经获得排名。
5. 每次新增或改写内容时重新运行 `npm run content:research` 与 `npm run verify`，保留研究收据和图片台账。

## 发布判定

**Conditional No-Go。** 功能与内容可以进入最终发布准备，但 300 张逐条图片未完成视觉验收前不建议公开部署。完成上述视觉门禁后可恢复 Go。
